# PhoneIDE

A powerful Android IDE designed for coding, building, debugging, and AI-assisted development directly on Android.

PhoneIDE brings a modern development workflow to mobile with a project explorer, code editor, terminal, Gradle integration, and an advanced AI coding agent.

---

## ✨ Features

- 📁 Project & File Explorer
- 📝 Kotlin/Android Code Editor
- ⚡ Gradle Build Integration
- 💻 Built-in Terminal
- 🤖 Advanced AI Coding Agent
- 🧠 Project-aware AI Context
- 💬 Persistent AI Chat History
- 🔍 Codebase Analysis
- 🛠️ Automated Error Fixing
- 📦 APK Installation
- 🌙 Dark & Light Theme
- 📱 Optimized for Android

---

# 🤖 Advanced AI Agent

PhoneIDE includes an AI Agent designed specifically for software development.

Unlike a simple AI chat, the Agent can understand the project, inspect files, reason about problems, make changes, run development commands, analyze errors, and verify the result.

The goal is to provide an experience similar to having a coding agent inside the IDE.

---

## 🧠 Project-Aware Intelligence

The AI Agent can work with the current project instead of treating every message as an isolated conversation.

It can understand:

- Project structure
- Source files
- Kotlin code
- Android resources
- Gradle configuration
- Build configuration
- Dependencies
- Existing implementation
- Error logs
- Previous conversation context
